Quickstart Guide

Set up a production-ready NexusDB instance in less than 2 minutes. Connect your application and start streaming data with real-time sync capabilities.

Installation

NexusDB is distributed as a single binary or a Docker container. For local development, we recommend using the CLI tool which handles local orchestration and environment variables automatically.

bash — terminal
1
npm install -g nexus-cli
2
nexus init my-project --template=typescript
3
# Initialize a new local cluster
4
nexus dev
➜ Local: http://localhost:3000
➜ Console: http://localhost:5432
ℹ Ready in 34ms

Connecting the Client

Once your instance is running, you can connect using the JavaScript client. NexusDB uses WebSockets for real-time updates and falls back to HTTP/2 for standard requests. The client handles reconnection logic automatically.

info
Type Safety NexusDB automatically generates TypeScript definitions for your database schema. Run nexus gen types to sync your local `d.ts` files.
src/db.ts
TypeScript
1import { createClient } from '@nexus/client'
2
3// Initialize with your project URL and public key
4const nexus = createClient(
5process.env.NEXUS_URL,
6process.env.NEXUS_ANON_KEY
7)
8
9// Subscribe to real-time changes on the 'users' table
10nexus
11.from('users')
12.on('INSERT', (payload) => {
13console.log('New user:', payload.new)
14})
15.subscribe()
