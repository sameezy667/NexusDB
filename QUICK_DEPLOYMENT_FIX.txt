❌ COMMON MISTAKES:

1. Only set in .env.local
   → .env.local is for LOCAL development only
   → Must set in deployment platform

2. Forgot to redeploy
   → Env vars are baked in at build time
   → Always redeploy after changing env vars

3. Wrong variable name
   → Must be: NEXT_PUBLIC_API_URL
   → Check spelling and NEXT_PUBLIC_ prefix

4. Backend not deployed
   → Deploy backend FIRST
   → Verify it's accessible
   → Then set frontend env var

🔍 DEBUGGING:

If still getting 404 after following steps:

1. Check browser console:
   console.log(process.env.NEXT_PUBLIC_API_URL)
   
   If shows undefined or "":
   → Variable not set correctly
   → Check deployment platform settings
   → Redeploy

2. Check Network tab (F12 → Network):
   
   If you see: /api/generate (relative path)
   → Environment variable not set
   
   Should see: https://your-backend.com/api/generate (absolute)
   → Environment variable is set correctly

3. Test backend directly:
   curl https://your-backend.com/docs
   
   If fails:
   → Backend is not deployed or not accessible
   → Deploy backend first
